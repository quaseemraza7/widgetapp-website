WIDGETAPP WEBSITE STARTER

Files
- index.html: responsive animated landing page + browser demo
- widgetapp-icon.png: supplied WidgetApp icon, trimmed and placed on transparent canvas

PREVIEW LOCALLY
Double-click index.html to open it in a browser.

FREE HOSTING (GitHub Pages)
1. Create a GitHub repository named widgetapp-website.
2. Upload index.html and widgetapp-icon.png to the repository root.
3. Open Settings > Pages. Select Deploy from a branch, branch main, folder /(root), then Save.
4. Wait for the Pages URL to appear. This is static hosting; no backend is included.

ANDROID APK
The download button is disabled intentionally. A signed APK is required for direct installation. An AAB is generally for app-store distribution and is not the file to link as a direct APK download. Build a signed APK in Android Studio, test it, then upload it and change the button link in index.html.
